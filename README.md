## 一、项目简介

本仓库是一篇**管理研究方法课程毕业论文（方法预演）**的完整交付物，核心目标是**完整走通一遍 NLP 测度构建的五步流水线**，并把研究成果整理为可复现的规范工程。

研究选题为：**企业数字化转型的文本测度如何构建？该测度是否可靠？它能否解释企业全要素生产率？**

具体完成以下工作：

| 环节 | 内容 |
|---|---|
| 构念界定 | 将"数字化转型"分解为**底层技术运用**（维度 A，47 词）与**技术实践应用**（维度 B，50 词）两个维度 |
| 词典构建 | 共 97 个术语的领域词典，逐词标注维度与来源文献 |
| 三路线并行 | 词典法（主测度）／词嵌入法（PPMI + 截断 SVD）／主题模型法（LDA 载荷加权） |
| 三层次指标 | L1 原始计数 ／ L2 标准化比率 ／ L3 对数测度 |
| 七项信效度 | 内容效度、聚合效度、区分效度、预测效度 ＋ 分半信度、内部一致性信度、重测信度 |
| 实证分析 | 基准回归、11 项稳健性检验、中介效应、异质性分析 |

**主要结论一览**

- 基准回归中 `Digital` 每提高 1 个单位，全要素生产率（LP 法）平均上升 **0.188** 个单位（t = 4.45），在 1% 水平上显著；该结论在 11 项稳健性检验中保持一致。
- 分半信度 **0.839**，Cronbach's α 为 **0.833—0.840**，跨方法一致性 Kappa 为 **0.815—0.857**，与词嵌入法／主题模型法测度的相关系数分别为 **0.972 / 0.922**。
- 研发投入是主要中介渠道，间接效应 **0.1176**（Sobel z = 3.85，Bootstrap 95% CI = [0.0517, 0.1818]），中介占比 **62.4%**。
- "底层技术运用"维度的生产率效应（0.137）约为"技术实践应用"维度（0.069）的两倍。

## 二、⚠️ 数据说明（请先阅读）

**本仓库用于方法演示与可复现性验证。** 受公开数据授权限制，仓库中的 MD&A 语料为**按真实年报语料统计特征合成的模拟语料**（synthetic corpus），财务变量同为模拟值。

模拟过程采用固定随机种子，**完全可复现**；语料按"潜变量 → 词典映射"机制生成：先为每家公司每年生成一个不可观测的数字化转型潜变量，再依据该潜变量决定文本中数字化句子的比例与词典词的使用倾向。这一设计使"文本—构念"之间具有可验证的对应关系，因此可以直接计算**测度对潜变量的回收率**（本文中 Spearman ρ = 0.725），用于检验流水线的有效性。

**在真实研究中如何替换为真实数据？**

```
data/raw/mda_corpus.csv       →  替换为从巨潮资讯网 / CNRDS 下载并经 PDF 解析的真实 MD&A 文本
                                 （列：firm_id, stock_code, firm_name, year, industry, region, SOE, HiTech, text）
data/raw/firm_financials.csv  →  替换为 CSMAR / Wind 导出的财务与治理面板
                                 （列：firm_id, year, industry, region, SOE, HiTech, Size, Lev, ROA,
                                  Growth, Age, Top1, Dual, Board, RD, Intangible, ITexec,
                                  DigitalInvest, TFP_LP, TFP_OP）
```

替换后，`code/01_corpus_acquisition.py` 的前半部分（模拟语料生成）可整体跳过，**其余五步流水线与全部代码无需修改**即可在原样本上复现。逐文件的数据来源与处理步骤说明见 [`docs/数据来源说明.md`](docs/数据来源说明.md)。

## 五、方法说明：NLP 测度的五步流水线

```
① 语料获取  →  ② 文本预处理  →  ③ 特征提取  →  ④ 指标构建  →  ⑤ 信效度检验
   定源          清洗/分词/          词典法           L1/L2/L3        4 类效度
   对齐          去停用词/           词嵌入法          三层测度        3 类信度
   留痕          词形归一            主题模型法        关键决策        仿真校验
```

**核心构造决策（三项，均在论文 3.3.4 中说明）**

1. **分母口径**：主测度取绝对命中词数的对数（`Digital = ln(1+命中词数)`）；稳健性中改用「命中词数 ÷ 有效词数」与「命中词数 ÷ 总句数」。
2. **是否加权**：主测度等权；稳健性中以两维度标准化后等权加总的复合测度替代。
3. **变量命名**：体现"构念 + 计算方式"，如 `Digital` / `Digital_ratio` / `Digital_vec` / `Digital_topic`。

**三条技术路线的实现要点**

| 路线 | 实现 | 特点 |
|---|---|---|
| 词典法 | 首字分桶 + 最长匹配优先 + 非重叠计数 | 透明、可复现，作为**主测度** |
| 词嵌入法 | 窗口 ±3 共现矩阵 → PPMI 加权 → 截断 SVD(100 维) → 与"数字化语义中心"的余弦相似度 | 可捕捉词典之外的近义表述 |
| 主题模型法 | LDA(K=10) → 主题"数字化载荷" → 载荷加权主题比例 | 无需人工先验 |

**信效度检验设计**

| 类别 | 检验方法 |
|---|---|
| 内容效度 | 词典维度构成、来源文献数、**跨方法标注一致性 Kappa**、测度—潜变量回收率 |
| 聚合效度 | 与词嵌入法／主题模型法测度、与无形资产占比／IT 人员占比／数字化资本支出占比的相关性 |
| 区分效度 | 与董事会规模、第一大股东持股、两职合一等**理论上不应相关**变量的相关性 |
| 预测效度 | 对研发投入与全要素生产率的回归 |
| 信度 | 分半信度（200 次随机对半 ＋ Spearman-Brown 校正）、Cronbach's α、重测信度 |
