# 数据来源与处理步骤说明

本文件逐项说明仓库中每一个数据文件（及关键中间产物）的**来源**与**处理步骤**，对应论文"3.2 数据来源与样本选择"与"3.3 测度指标构建思路"。

---

## 〇、总体说明

本项目为**管理研究方法课程的方法预演**。为使代码与结果完全公开、可复现，同时受公开数据授权限制，仓库中所附语料为**按真实年报语料的统计特征合成的模拟语料**，财务变量亦为模拟值。

**模拟语料并非随机文本**，而是按"潜变量 → 词典映射"机制生成：

1. 为每家公司生成不可观测的**企业数字化禀赋**（`digital_firm_effect`）；
2. 为每个（行业 × 年度）生成**行业共同数字化冲击**（`IND_YEAR_SHOCK`）；
3. 二者与行业技术密集度、高新技术资质、地区、产权性质、时间趋势及随机扰动共同组成**数字化转型潜变量**（`digital_latent`）；
4. 依据潜变量决定每份文本中"数字化句子"的比例（logistic 映射），并按一定概率从词典的维度 A / 维度 B 中抽取术语填入句子模板；
5. 因此文本中的词典命中词频与潜变量之间存在**可验证的统计对应关系**，可直接计算测度的**回收率**（本文中 Spearman ρ = 0.725）。

在真实研究中，只需替换 `data/raw/` 下的两个文件（见下文"替换指引"），`code/02`—`code/06` 与全部下游代码**无需修改**即可复现。

## 一、词典与停用词表（`data/dictionaries/`）

### `digital_dict.csv`
- **来源**：作者依据《管理世界》《中国工业经济》《财贸经济》等期刊中数字化转型主题文献所使用的术语表整理，并参考国家统计局《数字经济及其核心产业统计分类（2021）》。
- **处理步骤**：
  1. 从上述来源抽取候选术语，形成初始词表；
  2. 依据"领域专属性、构念指向性、可识别性"三条原则逐词筛选（剔除"创新""发展"等通用词）；
  3. 按技术深度将术语划分为**维度 A 底层技术运用**（47 词）与**维度 B 技术实践应用**（50 词）；
  4. 为每个术语标注所属维度、维度中文名与来源文献。
- **字段**：`word`（术语）、`dimension`（A/B）、`dimension_cn`（维度中文名）、`source`（来源文献）。
- **规模**：97 个术语（A 维度 47 个，B 维度 50 个）。

### `stopwords_general.txt`
- **来源**：中文通用停用词表（哈工大停用词表、百度停用词表的并集）＋ 标点与虚词补充。
- **处理步骤**：去重后按行存储，`#` 开头的行为注释。

### `stopwords_finance.txt`
- **来源**：作者依据年报语料的高频词分布人工整理，并参考财经文本分析相关研究。
- **处理步骤**：剔除去停用词后仍属"年报模板套话"的词（如"报告期内""上市公司""同比""归属于"），以避免模板化表述污染数字化信号。
- **合并后规模**：通用 + 财经 + 自定义停用词共 **298** 个。

> 注：`digital_userdict.txt` 由 `code/02_preprocessing.py` 自动生成（供 jieba 加载），无需手工维护。

## 二、原始数据（`data/raw/`）

### `mda_corpus.csv`
- **来源**：由 `code/01_corpus_acquisition.py` 按上述"潜变量 → 词典映射"机制合成。
- **真实研究中的替代来源**：巨潮资讯网（www.cninfo.com.cn）或 CNRDS 数据库下载的上市公司年度报告 PDF，经 PyMuPDF / pdfplumber 抽取"管理层讨论与分析"章节文本。
- **处理步骤**：
  1. 随机生成 300 家制造业上市公司的基本属性（行业、地区、产权性质、高新技术资质、上市年限）；
  2. 生成每家公司的企业数字化禀赋与每个（行业 × 年度）的共同冲击；
  3. 计算潜变量并标准化（`dig_std`）；
  4. 按 logistic 映射确定每份文本的数字化句子比例，从词典抽取术语填入 28 种数字化句子模板，并混入 74 种不含词典词的通用经营句子模板；
  5. 随机打乱句子顺序并前置一句含财务数字的"硬信息"句；
  6. 以固定随机种子导出。
- **字段**：`firm_id`、`stock_code`、`firm_name`、`year`、`industry`、`region`、`SOE`、`HiTech`、`text`。
- **规模**：2,100 行（300 家 × 7 年），平均文本长度约 2,295 字。
- **是否需要清洗**：是，进入 `code/02_preprocessing.py`。

### `firm_financials.csv`
- **来源**：由 `code/01_corpus_acquisition.py` 模拟生成。
- **真实研究中的替代来源**：
  - 财务与治理变量（Size、Lev、ROA、Growth、Age、Top1、Dual、Board）→ **CSMAR 中国上市公司财务报表数据库 / 治理结构数据库**；
  - 研发投入强度（RD）→ **Wind 数据库**；
  - 无形资产占比（Intangible）→ CSMAR 资产负债表；IT 人员配置比例（ITexec）→ 年报员工构成明细表（手工或正则抽取）；
  - 全要素生产率（TFP_LP / TFP_OP）→ 使用 CSMAR 财务数据，按 Levinsohn-Petrin（2003）与 Olley-Pakes（1996）方法自行估计。
- **处理步骤**：
  1. 依据潜变量与行业、资质特征生成 TFP_LP（含中介渠道 RD 与异质性交互项）；
  2. 由 TFP_LP 加噪声生成 TFP_OP，模拟两种生产函数估计方法的差异；
  3. 生成各控制变量（含与潜变量相关的 Intangible、ITexec、DigitalInvest 三个"数字化痕迹"指标，用于聚合效度检验）；
  4. 以固定随机种子导出。
- **字段**：`firm_id`、`year`、`industry`、`region`、`SOE`、`HiTech`、`Size`、`Lev`、`ROA`、`Growth`、`Age`、`Top1`、`Dual`、`Board`、`RD`、`Intangible`、`ITexec`、`DigitalInvest`、`TFP_LP`、`TFP_OP`。
- **规模**：2,100 行。
- **是否需要清洗**：是，缩尾处理在 `code/04_measure_construction.py` 中完成。

### `_simulation_truth.csv`
- **来源**：`code/01_corpus_acquisition.py` 输出。
- **用途**：保存每家公司每年的真实潜变量（`dig_std`），**仅用于校验流水线的有效性**（计算测度对潜变量的回收率），**不进入任何回归分析**。
- **处理步骤**：无需处理，直接读取。

### `annual_reports_sample/`（20 份 .txt）
- **来源**：从 `mda_corpus.csv` 随机抽取 20 个企业—年度观测导出。
- **用途**：便于人工查看合成语料的文本形态。
- **处理步骤**：仅作展示，不进入流水线。

## 三、中间与最终数据（`data/processed/`）

### `mda_clean.csv`
- **来源**：由 `code/02_preprocessing.py` 处理 `mda_corpus.csv` 得到。
- **处理步骤**：① 词形归一（全角转半角、简称统一）；② 文本清洗（去页眉页脚、页码、公告编号等模板噪声，保留句读标点）；③ jieba 精确模式分词（加载 97 词自定义词典）；④ 三维停用词过滤；⑤ 统计字符数、有效词数与句数。
- **字段**：`firm_id`、`year`、`text_clean`、`n_chars`、`n_tokens`、`n_sent`。

### `top_words_overall.csv`
- **来源**：步骤二输出的全样本词频统计（Top 300）。
- **用途**：用于人工核查停用词表是否充分、分词是否合理。

### `word_freq_digital.csv`
- **来源**：由 `code/03_feature_extraction.py` 的"路线一 词典法"输出。
- **处理步骤**：采用"首字分桶 + 最长匹配优先 + 非重叠计数"规则扫描 `text_clean`，统计每份文本中每个词典词的命中次数。
- **字段**：`firm_id`、`year`、`word`、`dimension`、`count`。
- **规模**：56,782 行。
- **用途**：除构造主测度外，还在步骤五中被透视成"文档 × 词"计数矩阵，用于计算分半信度与 Cronbach's α。

### `doc_features.csv`
- **来源**：由 `code/03_feature_extraction.py` 输出，汇总三条技术路线的文档级特征。
- **处理步骤**：
  - **路线一（词典法）**：统计命中总词数、维度 A 词数、维度 B 词数；
  - **路线二（词嵌入法）**：构建窗口 ±3 共现矩阵 → PPMI 加权 → 截断 SVD 降维至 100 维 → 计算文档词向量均值与"数字化语义中心"的余弦相似度；
  - **路线三（主题模型法）**：训练 K=10 的 LDA → 计算各主题的"数字化载荷"（主题词分布中落在词典词上的概率质量占比）→ 以载荷为权重对文档的主题比例加权求和。
- **字段**：`firm_id`、`year`、`n_tokens`、`n_sent`、`hits_total`、`hits_A`、`hits_B`、`cos_digital`、`topic_digital`、`topic_digital_load`。
- **规模**：2,100 行。

### `lda_topics.csv`
- **来源**：由 `code/03_feature_extraction.py` 输出。
- **用途**：记录 LDA 每个主题的数字化载荷、Top30 词中的词典词占比、是否为数字化主题、Top10 词，用于人工解释主题含义。

### `panel_firm_year.csv` ★（核心交付数据）
- **来源**：由 `code/04_measure_construction.py` 将 `doc_features.csv` 与 `firm_financials.csv` 按 `firm_id × year` 一对一合并。
- **处理步骤**：
  1. 构造 L1 原始计数（`RawCount`）；
  2. 构造 L2 标准化比率（`Digital_ratio` = 命中词数 ÷ 有效词数 × 100；`Digital_sent_ratio` = 命中词数 ÷ 总句数 × 100）；
  3. 构造 L3 对数测度（`Digital` = ln(1+命中词数)，为**主测度**；`Digital_A`、`Digital_B` 为分维度测度）；
  4. 构造虚拟变量 `Digital_dum`、复合测度 `Digital_comp`，并映射 `Digital_vec`、`Digital_topic`；
  5. 对所有连续变量在 1% 与 99% 分位缩尾；
  6. 按 `firm_id`、`year` 排序后输出 CSV 与 Excel 两版。
- **规模**：2,100 个企业—年度观测，300 家公司，7 个年度。

### `panel_firm_year.xlsx`
- 与 `panel_firm_year.csv` 内容完全一致的 Excel 版本，便于直接查看与二次处理。

## 五、替换指引：如何在本流水线上使用真实数据

| 步骤 | 操作 |
|---|---|
| 1 | 从巨潮资讯网下载年报 PDF，用 PyMuPDF 抽取 MD&A 章节，整理为 `mda_corpus.csv`（字段与现文件一致） |
| 2 | 从 CSMAR / Wind 导出财务与治理面板，整理为 `firm_financials.csv`（字段与现文件一致） |
| 3 | 将 `code/01_corpus_acquisition.py` 中"模拟语料生成"部分注释掉，改为直接读取上述两个文件 |
| 4 | 视需要扩充 `data/dictionaries/digital_dict.csv`（增加领域术语）与停用词表 |
| 5 | 依次运行 `code/02` → `code/06`，或直接运行 `python code/run_all.py` |
| 6 | 步骤五中"测度—潜变量回收率"一项在真实数据下不可计算（无潜变量），可跳过该行 |

其余步骤的代码逻辑与参数均无需改动。
